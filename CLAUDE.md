# Proje notları

- Motor: Godot 4.3, renderer: GL Compatibility (eski telefonlarda da çalışsın diye).
- Hedef: Android, dikey ekran, yalnızca arm64 APK.
- Derleme: `main` dalına her gönderimde GitHub Actions APK derler ve `son-surum` sürümüne yükler.
  İndirme linki: https://github.com/malisah61/unity-oyun/releases/download/son-surum/PenaltiUstasi.apk
- Kullanıcıyla Türkçe konuş; oyundaki metinler Türkçe.
- Kod değişikliğinden sonra derleme kaydında "Parse Error" / "SCRIPT ERROR" olmadığını kontrol et.
- Oyun içi becerilere bak: `.claude/skills/` (GDScript, mobil, spor oyunu, 3D malzeme, performans).
